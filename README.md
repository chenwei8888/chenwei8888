# 温度转换程序

这是一个用Python编写的交互式温度转换程序，支持华氏度(°F)和摄氏度(°C)之间的相互转换。

## 功能特点

- ✅ 摄氏度转华氏度
- ✅ 华氏度转摄氏度
- ✅ 用户友好的交互界面
- ✅ 输入格式验证
- ✅ 错误处理
- ✅ 常见温度参考提示
- ✅ 支持退出命令

## 使用方法

### 运行程序

```bash
python3 temperature_converter.py
```

### 输入格式

- **摄氏度转换**: 输入数字后跟字母C，例如: `25C`、`0C`、`100C`
- **华氏度转换**: 输入数字后跟字母F，例如: `77F`、`32F`、`212F`
- **退出程序**: 输入 `quit`、`exit` 或 `q`

### 使用示例

```
请输入要转换的温度 (或输入 quit 退出): 25C

转换结果:
25.0°C = 77.00°F
----------------------------------------

请输入要转换的温度 (或输入 quit 退出): 77F

转换结果:
77.0°F = 25.00°C
----------------------------------------

请输入要转换的温度 (或输入 quit 退出): 0C

转换结果:
0.0°C = 32.00°F
----------------------------------------
提示: 0°C 是水的冰点
```

## 转换公式

- **摄氏度转华氏度**: °F = (°C × 9/5) + 32
- **华氏度转摄氏度**: °C = (°F - 32) × 5/9

## 常见温度参考

| 摄氏度 | 华氏度 | 说明 |
|--------|--------|------|
| 0°C    | 32°F   | 水的冰点 |
| 37°C   | 98.6°F | 人体正常体温 |
| 100°C  | 212°F  | 水的沸点 |
| -40°C  | -40°F  | 摄氏度和华氏度相等的点 |

## 注意事项

- 程序支持正数、负数和小数输入
- 输入时字母大小写不敏感（C/c 和 F/f 都可以）
- 程序会自动处理输入错误并提示正确格式
- 使用 Ctrl+C 可以随时退出程序
